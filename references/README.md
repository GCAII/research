# Citation records

BibTeX records for the publications listed in the root README.

This folder contains citation records only. The papers themselves are hosted on
Zenodo; each file here carries the metadata needed to cite one of them.

## Naming

The filename is the Zenodo record ID, which is also the suffix of the DOI:

| File | DOI |
|---|---|
| `23310745.bib` | `10.5281/zenodo.23310745` |

## Using them

```latex
\bibliography{references/23310745}
